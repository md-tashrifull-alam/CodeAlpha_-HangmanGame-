# CodeAlpha_-HangmanGame-
Simple text-based Hangman game built with Python. The player guesses a hidden word one letter at a time with a maximum of 6 wrong attempts. Uses basic Python concepts like loops, conditionals, strings, lists, and the random module. Beginner-friendly and runs in console/Google Colab.
# Hangman Game

## Features

- 6 incorrect guess limit
